# MUJ Study Material Portal

Editorial, mobile-first study hub for **Manipal University Jaipur** students.

Notes, PYQs, YouTube playlists, and quiz practice — organized by year, branch, and subject.

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Framer Motion
- React Router

## Local setup

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run Oxlint |

## Project structure

```
src/
  components/ui/   # BentoCard, FloatingDock, FolderTab
  data/            # studyMaterial.ts — subjects, branches, PYQs
  pages/           # Home, Explore, Quiz
```
